# Terraform EC2 Deployment

## Project Overview
This project demonstrates how to provision an Ubuntu EC2 instance on
AWS using Terraform and Infrastructure as Code (IaC).

## Technologies Used
- AWS EC2
- Terraform
- Ubuntu
- AWS IAM

## Resources Created
- Ubuntu 22.04 AMI lookup
- EC2 instance: t3.micro
- Instance ID and public IP outputs

## Terraform Commands
```bash
terraform init
terraform fmt
terraform validate
terraform plan
terraform apply
terraform output
terraform destroy
